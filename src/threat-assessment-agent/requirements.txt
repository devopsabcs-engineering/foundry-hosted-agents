# Threat-assessment hosted-agent runtime dependencies (Increment 1 baseline).
# Pre-release/hosting SDK packages are pinned loosely since exact stable
# versions are not yet published; see the Phase 2 validation report for any
# install failures encountered in this environment.
#
# langgraph is intentionally NOT pinned to <0.4: azure-ai-agentserver-langgraph
# (currently 1.0.0b17) transitively requires langchain>=1.0.3, which requires
# langgraph>=1.2.11,<1.3.0. A direct langgraph<0.4 pin makes the dependency
# set unsatisfiable (verified: `pip install -r requirements.txt` fails with a
# resolution conflict). graph.py only uses the stable StateGraph/START/END
# API, which is unaffected by this range.
#
# langchain and langchain-openai are declared explicitly (Phase 5) because
# graph.py now imports `langchain.agents.create_agent` and
# `langchain_openai.AzureChatOpenAI` directly to bind specialist nodes to
# Foundry Toolbox MCP tools via `use_foundry_tools`. Both ranges match the
# transitive constraints already required by azure-ai-agentserver-langgraph
# and langchain-azure-ai, so this does not change dependency resolution.
